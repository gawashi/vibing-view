# Requirements: 自作チャートアプリ（TradingView 代替）

**Defined:** 2026-07-18
**Core Value:** 自分の手元で、制限なく、好きなだけチャートを並べて指標を重ねられること

## v1 Requirements

初回リリースのスコープ。各要件はロードマップのフェーズに対応する。ユーザーが求める v1 ゴールライン（ウォッチリスト＋レイアウト保存が動く）を満たす全体。

### Data & Cache（データ取得・キャッシュ）

- [ ] **DATA-01**: ユーザーは米国株・暗号資産の銘柄をティッカー／名称で検索し、チャート対象として選べる
- [ ] **DATA-02**: 価格データ（OHLCV）はプロバイダ非依存のデータソース層経由で取得する（v1 の実装は FMP のみ）
- [ ] **DATA-03**: 取得した価格データはローカルに永続キャッシュされ、再表示時は再取得せず、不足範囲（ギャップ）だけを取得する（キャッシュ優先）
- [ ] **DATA-04**: FMP 無料枠で使えない足・エンドポイントを実行時に検知し、破綻せず段階的にデグレードする。有料キーに切り替えるとコード変更なしで全機能が有効になる
- [ ] **DATA-05**: 各ユーザーは自分の FMP API キーを設定でき、キーは特権プロセスに安全に保管され、レンダラー（UI）側に露出しない

### Chart（チャート描画）

- [ ] **CHART-01**: ユーザーは選択した銘柄のローソク足チャートを表示できる
- [ ] **CHART-02**: ユーザーは時間軸を 1分/5分/15分/1時間/日/週/月 で切り替えられる（週・月は FMP が返さない場合は日足から導出する）
- [ ] **CHART-03**: ユーザーは時間軸方向にパン・ズームできる
- [ ] **CHART-04**: ユーザーは十字カーソルで価格・時刻を読み取れ、価格ペインと全指標サブペインで同期する
- [ ] **CHART-05**: アプリはダークテーマで表示する

### Indicators（指標）

- [ ] **IND-01**: 指標は差し込み可能な指標インターフェース（計算関数＋パラメータスキーマ＋描画先メタデータ）の背後に実装し、チャート描画コードを変えずに新指標を追加できる
- [ ] **IND-02**: ユーザーは移動平均（SMA/EMA を選択可）をオーバーレイとして、複数インスタンス同時に追加できる
- [ ] **IND-03**: ユーザーはボリンジャーバンドをオーバーレイとして追加できる（既定: 20期間・2σ）
- [ ] **IND-04**: ユーザーは出来高を専用ペインに追加できる
- [ ] **IND-05**: ユーザーは RSI を専用ペインに追加でき、買われすぎ/売られすぎの水準を設定できる（既定: 14 / 70 / 30）
- [ ] **IND-06**: ユーザーは MACD を専用ペインに追加できる（MACD 線・シグナル・ヒストグラム、既定: 12/26/9）
- [ ] **IND-07**: ユーザーは 1チャートあたり任意の数の指標インスタンスを自由に追加・表示切替・削除できる（個数上限なし）
- [ ] **IND-08**: ユーザーは各指標インスタンスのパラメータ（期間・ソース・色・しきい値）をライブに編集できる
- [ ] **IND-09**: 指標の計算値は TradingView の慣行と一致する（RSI=Wilder 平滑、MACD=EMA、BB=母集団標準偏差、正しい EMA シード）

### Layout & Persistence（レイアウト・保存）

- [ ] **LAYOUT-01**: ユーザーは複数チャートをグリッド（例: 1x1 / 2x1 / 2x2）で同時表示でき、各セルは独立（銘柄・時間軸・指標）
- [ ] **LAYOUT-02**: チャート／レイアウトの状態はシリアライズ可能な設定モデル（銘柄・時間軸・指標インスタンス＋パラメータ・グリッド配置）として一元管理する
- [ ] **LAYOUT-03**: ユーザーは名前付きレイアウトを保存し、後で復元できる
- [ ] **LAYOUT-04**: 起動時に直近／既定のレイアウトが自動復元される

### Watchlist（ウォッチリスト）

- [ ] **WATCH-01**: ユーザーはウォッチリスト（銘柄の追加・削除・並べ替え）を管理でき、セッションをまたいで永続する
- [ ] **WATCH-02**: ユーザーはウォッチリストの銘柄をクリックしてアクティブなチャートに読み込める

## v2 Requirements

将来リリースに繰り延べ。追跡するが現ロードマップには含めない。トリガー: v1 ゴールライン（ウォッチリスト＋レイアウト保存）が動き、日常利用に入ってから。

### Indicators / Charting

- **IND2-01**: 出来高移動平均のオーバーレイ（例: 20期間 SMA）
- **IND2-02**: 指標プリセット／テンプレート（"いつもの構成"をまとめて新チャートに適用）
- **LAYOUT2-01**: レイアウト内ペインのドラッグ・リサイズ

### Watchlist / Data

- **WATCH2-01**: 複数ウォッチリスト
- **DATA2-01**: 抽象化層の背後に 2つ目のデータプロバイダを追加（日本株・暗号資産特化データなど）

### AI / Integration（Claude 連携）

- **AI2-01**: MCP サーバーでアプリのキャッシュ済みデータ／指標を公開し、Claude Code／Desktop から問い合わせ・分析できる（TypeScript MCP SDK）
- **AI2-02**: チャート／指標データを Claude API に送り、アプリ内に AI 分析を表示する

## Out of Scope

明示的に除外。スコープクリープ防止のため理由付きで記録。

| Feature | Reason |
|---------|--------|
| 日本株 | FMP のカバレッジが弱い。将来 2つ目のプロバイダ（DATA2-01）で対応検討 |
| リアルタイム（分未満）ストリーミング配信 | 遅延 OK の使い方で不要。WebSocket 基盤は純粋な複雑さ |
| 描画ツール（トレンドライン・フィボ等） | v1 ゴールラインに含まれず、UI/操作の実装コストが大きい。コア完成後に再検討 |
| 価格アラート・通知 | バックグラウンドのスケジューラ／通知基盤が必要。手動チェックで足りる |
| マルチユーザー認証・クラウド同期・共有ワークスペース | 各自がローカルに自分のキーで動かすため不要 |
| 一般公開・ストア配布 | v1 は身内・少人数の共有まで |
| ユーザー記述の指標スクリプト（Pine Script 相当） | DSL＋サンドボックス実行は別プロジェクト規模。開発者がコードで指標を足す設計で足りる |
| スクリーナー／市場スキャナー | 大量の横断取得が必要で FMP 無料枠を圧迫。ウォッチリストで足りる |
| ニュース／ファンダメンタルズ・パネル | 別データ領域・別 UI、需要なし |
| バックテスト／ストラテジーテスター | シミュレーション基盤が必要で別プロダクト領域 |
| ソーシャル／コミュニティ機能 | 個人・少人数ツールに無関係 |
| モバイルアプリ | Windows デスクトップ限定（PROJECT.md 制約） |
| AI によるチャートパターン自動認識 | 需要なし。"制限なしの手動チャート"というコア価値と直交 |
| 複数チャート間の十字カーソル連動 | v1 ゴールを超える複雑さ。v1.x で日常利用時に必要なら再検討 |
