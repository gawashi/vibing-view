# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Scope: app shell + chart area, symbol search, settings/API-key screen, and the chart's dark-theme
> tokens. Timeframe switcher, indicators, panes, crosshair, multi-chart grid, watchlist are out of
> scope (Phases 2–5) — this contract intentionally does not cover them.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn (recommended, **not yet initialized** — greenfield repo, no `package.json`/Vite project exists yet) |
| Preset | `zinc` base color, CSS variables, dark-mode-only (no light/dark toggle — CHART-05 mandates dark) |
| Component library | Radix UI primitives (via shadcn) |
| Icon library | lucide-react (shadcn default, tree-shakeable, no extra choice needed) |
| Font | System UI stack (`ui-sans-serif, -apple-system, "Segoe UI", sans-serif`) — zero added font dependency; Windows' Segoe UI already renders tabular figures acceptably for price/OHLC numerals |

**Structural note (not a template row, load-bearing for executor):** No router library is in the approved stack (CLAUDE.md). Settings (DATA-05 API-key entry) renders as a modal `Dialog` over the single chart view, not a separate route — avoids adding a routing dependency for one screen.

**shadcn gate outcome:** Since this is a from-scratch repo, `npx shadcn init` cannot run yet (no `vite.config`/`package.json` to init into). Recommendation: initialize shadcn as part of Phase 1's project-scaffolding task, using preset `zinc` + CSS variables + dark mode forced on. This is a proposed default, not yet confirmed interactively — **flagged for user confirmation in the return message**, not a hard block on writing this contract.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing (search result row internal padding) |
| md | 16px | Default element spacing (search bar ↔ chart gap, settings form fields) |
| lg | 24px | Section padding (settings dialog padding, chart area padding) |
| xl | 32px | Layout gaps (app shell outer margins) |
| 2xl | 48px | Major section breaks (not expected to be used in Phase 1's single-view shell) |
| 3xl | 64px | Page-level spacing (not expected to be used in Phase 1) |

Exceptions: none — desktop mouse-driven app, no 44px touch-target exception needed.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label | 12px | 400 (regular) | 1.4 |
| Heading | 18px | 600 (semibold) | 1.2 |
| Display | 24px | 600 (semibold) | 1.2 |

Only two weights used app-wide: 400 regular, 600 semibold. Display is used for the active symbol
ticker + last price in the chart header — the single largest text in Phase 1's UI.

## Color

| Role | Value | Usage |
|------|-------|-------|

| Secondary (30%) | `#151920` | Search bar container, settings dialog surface, header bar |

| Chart Down | `#EF4444` | Candlestick body/wick, down bars only (lightweight-charts theme option) |

Accent reserved for: primary CTA buttons, input focus rings, selected list-row state — nothing else
(never body text, never decorative icons, never all interactive elements generically).

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (symbol search) | "Search" (button) / placeholder "Search ticker or company (press Enter)" — confirm-based, no incremental search per D-01 |
| Secondary CTA (settings) | "Save API Key" |
| Destructive confirmation | Clear saved API key: "Remove your saved FMP API key? You'll need to re-enter it to fetch new data. Already-cached charts keep working offline." |
| Empty state heading | "No matches found" (search results) |
| Empty state body | "Try a different ticker or company name. Search covers US stocks and crypto." |
| Loading state | "Loading chart…" (first fetch), "Searching…" (search in flight) |
| Error state | "Couldn't load chart data. Check your connection or your FMP API key in Settings, then try again." |
| safeStorage-unavailable warning | "Your OS doesn't support secure credential storage. Your API key will be saved in plain text on this device — avoid using this app on a shared machine until this is resolved." (D-05: explicit, never silent) |

## UI Considerations

Applicable state considerations resolved: 8 covered, 2 backstop, 0 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | search results (list-collection) | ✅ covered | Renders the documented "No matches found" copy above |
| loading | search results (list-collection) | ✅ covered | Inline "Searching…" row replaces the list while the confirmed query is in flight |
| loading | chart area (media) | ✅ covered | "Loading chart…" skeleton/spinner shown until first candle data resolves (cache hit or FMP fetch) |
| error | search results (list-collection) | ✅ covered | Reuses the documented Error state copy, shown inline below the search bar |
| error | chart area (media) | ✅ covered | Reuses the documented Error state copy, shown in the chart canvas area in place of candles |
| error | settings form (form) | ✅ covered | safeStorage-unavailable warning copy renders persistently in the settings dialog when `isEncryptionAvailable()` is false |
| populated | search results (list-collection) | ✅ covered | Up to 8 result rows visible (ticker, name, exchange badge); beyond 8, internal scroll — no pagination |
| zero-one-many | search results (list-collection) | ✅ covered | 0 = empty-state copy; 1 or many = identical row styling, no singular/plural copy variance needed |
| overflow / long-text | company name in search result row (static-content) | 🧪 backstop | Truncate with ellipsis at row width, native `title` tooltip shows full name on hover — needs a visual check once real FMP result data (long names) is available |
| long-text | API key input (form) | ✅ covered | Native HTML input handles overflow/scroll of a long pasted key string with no custom code |
| partial | search results / settings form | dismissed | N/A — search hits are atomic (no partial-row shape), settings form is a single API-key field with no multi-field partial state |
