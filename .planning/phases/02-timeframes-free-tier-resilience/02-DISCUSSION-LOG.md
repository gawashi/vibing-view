## 無料枠の制限UX

### gated な足のボタン表示
| Option | Description | Selected |
|--------|-------------|----------|
| グレーアウト+バッジ | 薄く表示＋鍵バッジ、ホバーでツールチップ。状態が一目で分かる | ✓ |
| 押せるが状態表示 | 通常表示、押すとチャート領域に状態を出す | |

### 「要上位プラン」と「レート制限」の区別
| Option | Description | Selected |
|--------|-------------|----------|
| 区別する | 永続的なプラン制限 vs 明日直る、を別メッセージで | ✓ |
| 区別しない | どちらも「今は使えない」で同じ表示 | |

### gated/制限の足のチャート領域
| Option | Description | Selected |
|--------|-------------|----------|
| メッセージオーバーレイ | チャート領域に制限の説明を出す | |
| 直前の足を維持 | 切替を弾き直前の足を表示したままトースト通知 | |
| グレーアウト+選択不可 | そもそも切り替えられないようにする（ボタンで完結） | ✓ |

**User's choice:** グレーアウト+バッジ / 区別する / グレーアウト+選択不可（切替を弾く）
**Notes:** D-13/D-14/D-15。gated 足は選択不可なので空チャート問題は起きない。表示中の足が途中でレート制限に達したケースはキャッシュ済みバー維持＋通知（planner裁量）。

## パン取得とW/M導出のAPI節約

### パンで未キャッシュ履歴に入ったときの取得
| Option | Description | Selected |
|--------|-------------|----------|
| 自動（不足分だけ） | 左端接近で不足サブレンジを自動取得（デバウンス付き） | ✓ |
| 手動「もっと読む」 | ボタンで明示要求時だけ取得 | |

### 週足・月足の作り方
| Option | Description | Selected |
|--------|-------------|----------|
| 常に日足から導出 | native W/M は叩かず日足を集約。追加リクエストゼロ | ✓ |
| nativeを試してfallback | FMP W/M を試し、なければ日足導出 | |

### intraday の初回取得量
| Option | Description | Selected |
|--------|-------------|----------|
| 直近の必要分だけ | 直近スパンだけ取得、さかのぼりはパン取得に任せる | ✓ |
| できる限り一括 | 初回に取れるだけ遡って一括取得 | |

**User's choice:** 自動（不足分だけ） / 常に日足から導出 / 直近の必要分だけ
**Notes:** D-16/D-17/D-18。すべて API 節約最優先方針に直結。

## 無料枠の検知方法

### gated 判定方法
| Option | Description | Selected |
|--------|-------------|----------|
| レスポンスから自動検知 | 403/エラー形 payload を見て判定、結果をキャッシュ | ✓ |
| ユーザーがプラン申告 | 設定で自分のプランを選ぶ | |

### レート制限の認識
| Option | Description | Selected |
|--------|-------------|----------|
| FMPのエラー反応で判定 | 429/レート制限メッセージを検知 | ✓ |
| ローカルカウント | 既知の上限をローカルで数えて上限前に止める | |

### capability 再プローブのタイミング
| Option | Description | Selected |
|--------|-------------|----------|
| 足を初めて使うとき遅延 | キー変更で無効化→各足の初回要求時にプローブ | ✓ |
| キー変更時に即全プローブ | キー入力の瞬間に全 intraday 足をプローブ | |

**User's choice:** レスポンスから自動検知 / FMPのエラー反応で判定 / 足を初めて使うとき遅延
**Notes:** D-19/D-20/D-21。実レスポンスを真実源にし、無駄打ちを避ける。

## Claude's Discretion

- 単一区間カバレッジ（D-09）の連続拡張での維持、多区間モデルは P2 不要。
- FMP intraday エンドポイント選定・レンジページング・gated/レート制限の具体的レスポンス条件。

- capability キャッシュの保管方式・TTL・キー変更時の無効化。

- 時間軸ボタン列・バッジ・トーストの具体的な見た目。
- パン自動取得のデバウンス閾値・先読み量。
