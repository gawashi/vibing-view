## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user input → edit-form fields | Number/enum/source/color inputs flow through store actions to pure client compute + chart options. No network, no persistence, no privileged IPC. |
| renderer ↔ main IPC | Unchanged — the edit form and legend add no IPC and no query; they only call in-memory store actions. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-04 | Denial of Service | live recompute on keystroke | low | mitigate | Client compute is O(n) and cheap; native number `min`/`step` bound values; a short debounce on updateParams is available (D-26) if continuous typing feels heavy — add only if observed. |
| T-03-05 | Tampering | color / source / type values | low | accept | Values are hex strings / fixed enum members used as chart options and math inputs; no innerHTML/eval/SQL sink. Canon-security breadcrumb (dropped): native `<input type=color>` yields a hex string, not markup — no XSS. |
| T-03-06 | Spoofing / Repudiation / Info-disclosure / Elevation | — | n/a | accept | No secrets/auth/network/persistence/privileged op introduced — not applicable. |
| T-03-SC | Tampering (supply chain) | npm installs | n/a | accept | Zero new dependencies (reuses installed Dialog/Input/ToggleGroup/Tooltip/Button + lucide icons + native `<input type=color>`). No install to audit. |
</threat_model>
