## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user input → BB params | Period / σ / source / color feed pure client compute (bollinger) and a canvas primitive. No network, no persistence, no privileged IPC. |
| renderer ↔ main IPC | Unchanged — BB and the band primitive add no IPC and no query; they compute over the already-cached barsRef. |

| T-03-07 | Denial of Service | band primitive redraw / bollinger over many BB instances | low | mitigate | bollinger is O(n) over loaded bars; the polygon draw is a per-frame canvas fill bounded by the visible range. If draw cost is observed high, the ponytail 3-line fallback (DESIGN §5) removes the primitive entirely — BB still works. |
| T-03-08 | Tampering | σ / period / color values | low | accept | Numeric/enum/hex inputs used as math inputs and canvas fill style; no innerHTML/eval/SQL sink. Canon-security breadcrumb (dropped): color is a hex/opacity string for canvas fillStyle, not markup — no XSS. |
| T-03-09 | Spoofing / Repudiation / Info-disclosure / Elevation | — | n/a | accept | No secrets/auth/network/persistence/privileged op introduced — not applicable. |
