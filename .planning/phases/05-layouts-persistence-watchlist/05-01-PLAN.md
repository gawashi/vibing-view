<objective>
This is the **phase tracer** — the thinnest end-to-end slice that proves the persistence spine before any grid/layout/watchlist expansion. It promotes the single-global chart store into a serializable **cell-array Workspace**, renders ONE cell from it, auto-saves the current workspace to `userData/layouts.json`, and auto-restores it on startup — a full round-trip through every layer this phase will touch (store → serialize → main JSON persist via typed IPC → restore → render).

Purpose: prove the cell-model + persistence architecture on the executor's best early-context tokens, so an architectural dead-end is caught after one slice, not after the grid/layouts/watchlist are already built on top.
Output: `Cell`/`GridShape`/`Workspace` types, a cell-based Zustand store, pure `workspace.ts` helpers, a main-process `layoutStore` with atomic writes + defensive parse, typed `layout:getCurrent/setCurrent` IPC, and App/Chart wired to render + persist + restore the active cell.
</objective>

<assumption_delta_decision>
**FIRED: pluralization — single global chart → collection of independent cells.**
- **Primary noun (generalized):** the **grid cell** = `{ symbol, timeframe, indicators }`. The workspace = an array of up to 4 cells + a grid shape + an active-cell id.
- **Decision: `promote`.** The single-global store (`store.ts`'s one `activeSymbol` / `indicators` / `crosshair`) is DEMOTED to "the 1x1 / cell-0 case" of the cell array — NOT kept alongside a separate single-chart path (D-61 explicitly overrides D-31). One representation, not two.
- **Rationale:** D-54/55/60/61 — cells are independent, hidden cells retain config, expand duplicates the active cell, indicator sets are per-cell and disk-persisted.
- **Invariant test (this plan):** every cell round-trips its own symbol/timeframe/indicators independently through save→restore; goes red if shared-global chart state is ever reintroduced.
- **Consumer strategy (keeps churn low):** instance ids are globally unique (module-level `nextId`), so id-based CRUD (`removeIndicator`/`toggleVisible`/`updateParams`/`setColor`) scans all cells by id — their signatures DO NOT change. Only `addIndicator`/`setActiveSymbol`/`setTimeframe` retarget the **active** cell. `crosshair` stays global in this tracer (one cell) and becomes per-cell in 05-02 (grid) — it is transient view state, not part of the persisted Workspace.
</assumption_delta_decision>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| disk (`userData/layouts.json`) → main → renderer | Persisted JSON is untrusted (manual edit, prior-version bug, disk corruption) and crosses into app state on restore |
| renderer → main (typed IPC `layout:*`) | Workspace payload crosses the process boundary; main persists it as opaque JSON |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Tampering/DoS | `layoutStore.getCurrent` + renderer `parseWorkspace` (startup restore) | medium | mitigate | `parseWorkspace` never throws; corrupt → discard → defaults; partial/old-schema → fill defaults; `readJsonFile` try/catch fallback; startup never blocks (LAYOUT-04 / UI-SPEC E4) |
| T-05-02 | Tampering | `jsonStore.writeJsonFile` (layouts.json) | medium | mitigate | Atomic temp-file + `renameSync` so an interrupted/concurrent write never truncates or corrupts existing saved data (LAYOUT-03 concurrency) |
| T-05-03 | Information Disclosure / Injection | persisted `symbol`/text strings rendered in the renderer | low | accept | React escapes text nodes by default (no `dangerouslySetInnerHTML`); symbols pass as data through parameterized IPC/query keys, never interpolated into SQL/shell — no injection surface for a single-user local app |
</threat_model>
