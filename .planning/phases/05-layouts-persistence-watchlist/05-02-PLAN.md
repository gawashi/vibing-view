| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-05-G1 | Tampering | persisted `shape` / `activeCellId` coerced by `parseWorkspace` (05-01) | low | mitigate | `parseWorkspace` coerces `shape` to a valid `GridShape` enum (else '1x1') and `activeCellId` to an existing cell (else cell 0), so an out-of-range shape can never render an undefined grid; extend 05-01's parse tests to cover an invalid shape value |
| T-05-G2 | Denial of Service | rendering N live lightweight-charts instances | low | accept | Grid is capped at 4 cells (D-51); hidden cells are unmounted (chart.remove() disposes their canvas/observers per Chart.tsx cleanup) — resource use is bounded for a desktop app |
